# COS 201 - Programming I
## Week 3 Practical: Variables and Input/Output

This folder contains three Java programs demonstrating variables, user input, calculations, and output.

### Programs

1. **SimpleCalculator.java** — accepts two numbers and displays their sum, difference, product, and quotient. It checks for division by zero.
2. **AverageCalculator.java** — accepts a student's name and three scores, then calculates the total and average.
3. **ItemCost.java** — accepts an item name, quantity, and unit price, then calculates the total cost.

### Learning Outcome
To practise declaring variables, receiving input with `Scanner`, performing arithmetic operations, and displaying results.
